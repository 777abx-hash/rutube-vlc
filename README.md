# Rutube → VLC

Батник, который по ссылке на ролик Rutube достаёт прямую HLS-ссылку и открывает её в VLC — с названием видео вместо куска URL в заголовке плеера.

 Главная цель и плюс данного скрипта — это воспроизведение контента с RuTube без рекламы.

## Требования

- Windows 10/11
- [VLC](https://www.videolan.org/vlc/) (проверено на 3.0.24), путь по умолчанию: `C:\Program Files\VideoLAN\VLC\vlc.exe`
- [yt-dlp](https://github.com/yt-dlp/yt-dlp), доступный в `PATH`:

```powershell
pip install -U yt-dlp
```

## Использование

1. Запустить `rutube_link.bat` (двойным кликом).
2. Вставить ссылку на видео Rutube, например `https://rutube.ru/video/************************`.
3. Нажать Enter — откроется VLC и начнётся воспроизведение.

В окне консоли появится строка `Название: "…"`, а в VLC будет показано название ролика.

## Как это работает

1. Один запрос к `yt-dlp` с ключами `-e -g` печатает две вещи: сначала название видео, затем прямую ссылку на поток (для Rutube это HLS/`.m3u8`).
2. Вывод пишется во временный файл в `%TEMP%`, откуда скрипт читает первую строку как название, вторую — как ссылку. Временный файл сразу удаляется.
3. VLC запускается с параметрами:
   - `--file-caching=3000`, `--network-caching=3000` — буфер 3 секунды, чтобы поток не «дёргался»;
   - `--meta-title="Название"` — подменяет отображаемое имя медиа, поэтому в плеере видно название фильма, а не часть ссылки.

Название и ссылка берутся за один проход, так что лишней задержки по сравнению со старой версией нет.

## Особенности реализации

- `chcp 65001` и `PYTHONIOENCODING=utf-8` — без них кириллица из `yt-dlp` приходит в cp1251 и в VLC попадает «кракозябрами».
- Сам `.bat` сохранён в UTF-8 **без BOM** и с переводами строк CRLF. Если пересохранить его в другой кодировке, русский текст в консоли сломается.
- Если название получить не удалось, скрипт просто открывает поток без `--meta-title` — ведёт себя как прежняя версия.
- Для плейлистов стоит `--no-playlist`: обрабатывается только первая ссылка.

## Если что-то не работает

| Проблема | Что проверить |
| --- | --- |
| `Ошибка: не удалось получить ссылку на видео` | Ссылка верная и открывается в браузере? `yt-dlp` установлен в `PATH` (`yt-dlp --version`)? Обновить: `pip install -U yt-dlp` |
| VLC не запускается | Проверить путь к `vlc.exe` (см. ниже) |
| В названии «кракозябры» | Батник пересохранён не в UTF-8 без BOM |
| Поток тормозит / буферизуется | Увеличить `--network-caching` (значение в миллисекундах) |

Если VLC установлен в другое место, поправьте путь в двух строках с `start ""`:

```bat
start "" "C:\Program Files\VideoLAN\VLC\vlc.exe" ...
```
